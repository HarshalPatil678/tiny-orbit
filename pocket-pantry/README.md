# Pocket Pantry

A small list for keeping an eye on the ingredients already at home. Add an item, jot down an amount if it helps, and add a best-by date when you know it.

## Open it

Open `index.html` in a current browser. No build step, account, or server is needed.

## What it does

- Keeps items in this browser, sorted by best-by date
- Shows what is dated today or within the next three days
- Filters to soon-to-use items or anything with a date
- Searches names and amounts, and removes items one at a time
- Works on a phone-sized screen and respects reduced-motion settings

The list is saved in local storage on this device. It does not sync to another browser or send your pantry data anywhere. **Clear list** removes saved items after a confirmation. No sample ingredients are added for you.

## A note on dates

Best-by dates are reminders, not food-safety advice. Use your own judgment about whether something is still good.

## A few choices

Pocket Pantry uses plain HTML, CSS, and JavaScript so it can be opened directly. The typefaces are loaded from Google Fonts when available; system fonts take over if they are not. The app itself has no third-party scripts.
